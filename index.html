Reels Hub Shipped
TypeScript Node.js Telegram Bot API FFmpeg

Commercial project (Jul 2026) — developed, shipped and sold. Mass-posting farm for Instagram Reels, run entirely from Telegram: one bot pushes the same reel across a whole pool of accounts through the Instagram API. TypeScript on Node.js, Telegram Bot API for the whole control surface, FFmpeg pipeline for re-encoding. Handed over with docs and a working deploy; sold July 2026.
